# 预览来源

`rtl_fade.gif`和`rtl_contact_sheet.png`均来自实际`team_fade_effect`仿真的RGB输出，不是用Python另写一套淡化算法生成的示意动画，也不是板卡录像。

仿真输出160×120、75幅完整画面，共1,440,000个有效像素。测试平台逐拍核对RGB888、HS/VS/DE及坐标；生成器另外检查所有同图相邻帧的颜色单调性、全黑帧和最终帧身份。GIF按名义60fps播放，颜色经GIF调色板量化，RGB888数值核验以仿真为准。

`preview_frames.txt`每行依次为：源帧序号、gain、phase、当前实际读取帧区。默认案例第34～38帧为黑色；第38帧后端已换到slot1，第39帧才开始淡入。其间模拟了后端请求接受与旧读数据排空的延迟。

预览的小画面用于缩减文件和测试时间。另有独立640×480、12帧、3,686,400个有效像素的完整视频案例，不生成大预览文件。
