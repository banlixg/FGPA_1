| 位 | 值 | 含义 |
|---|---|---|

| 内部错误码 | 0 | **SDRAM 写后读回校验通过**（修复前恒为 5） |

## 结论

- `team_sdram_port` 的"写后读回校验"在真板上**通过**，四张 BMP 成功写入帧区。
- 根因（实测确认）：
  1. 原实现用 `Sdr_busy`/`Sdr_init_ref_vld` 作命令门控 → 命令被静默丢弃（基线不做该门控）；
  2. 本板 SIP **单拍写/读不可靠**（有回应但数据为 FFFF），**连发 4 拍**才稳定（自检 v3 与 v6/v5 对照）。
- 采用：写/读各 4 拍突发、同地址、第 4 个回应比对；写前地址数据提前一拍稳定（PREP）。
