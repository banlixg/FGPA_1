# 验收目标（给持板队友）

> 状态：**代码功能已集成，实板调试未完成**。本文只定义"什么算通过、按什么顺序做、要交什么证据"，
> 不重复已有功能实现，也不需要重做架构。
>
> 当前整体判断：音频已能在板上循环播放（同事实测）；淡入淡出已接入代码并通过仿真；
> **唯一硬阻塞是 SDRAM 写入/读回异常 → 4 张图装不进帧区 → 黑屏**。
> 修复顺序必须从 SDRAM 开始，否则后面所有显示相关项都无法观察。

## 第 0 步：接手前先对齐现状（5 分钟）

1. 确认板上当前跑的是哪一版：数码管 `bs=5 / count=0 / err=F / as=4` 说明跑的是本目录分析的候选版且图未加载。
2. 确认 **TF 卡根目录**只有 4 个 `IMG000x.BMP` + `AUDIO.WAV`（旧素材移到子目录，程序只扫根目录）。
3. 确认 **板上 `DIG/LED` 开关拨到"数码管"**（否则数码管全灭，会被误判为死机）。
4. 记住本板的两个已确认事实（省得重复踩）：
   - **JTAG 临时下载（PROGRAM_SRAM）在本板不可靠**：报 `PROGRAM OK` 但配置不生效 → 一律走 **QSPI Flash + 断电冷启动**。
   - 代码里 `raw_rst_n = rst_n && sys_lock && video_lock`：**任一 PLL 没锁就整机复位**（数码管全灭 + 无 HDMI）。

---

## 第 1 步（阻塞项）：修好 SDRAM，恢复写后读回校验

**通过标准**

- [ ] 使用 `artifacts/sdram_self_test/` 自检设计，**单笔**写→读回数据正确（不是只测连发多笔）。
- [ ] 主设计恢复 `VERIFY_ENABLE=1` 后，数码管 **内部错误码位 = 0**（不再是 5）。
- [ ] 数码管 **count 位 = 4**（四张图全部驻留），`bs=5`（启动流程正常结束）。
- [ ] 至少连续两次冷启动都能达到 `count=4`（排除偶发）。

**已知根因与建议**（详见 `ANALYSIS.md`）

1. 已确认：端口把 `Sdr_busy / Sdr_init_ref_vld` 当门控，命令会被静默丢弃（自检 v2 无响应 vs v3 通过）。
   已按基线做法改为 `available = mem_initialized`（补丁已在本目录 `patches/`）。
2. 仍存的问题：**单笔写 → 单笔读** 数据不正确，怀疑
   - 写地址/数据与 `App_wr_en` 同拍更新，SIP 采样到的是上一拍值；
   - 读数据与 `Sdr_rd_en` 的相位对不齐（可能早/晚一拍）。
   **建议**：把地址/数据提前一拍稳定再发单拍写脉冲（或把写脉冲拉成 2 拍）；读侧把 `Sdr_rd_en` 当拍与延后一拍的 `Sdr_rd_dout` 都打印/显示出来比对。
3. 相位：自检通过用的是 **180°**（`CLKC2_CPHASE=9`），基线也是 180°。若改回 144° 需重新验证。
4. 注意：本轮 180° 版本重编后 **SWNS −0.565 ns / STNS −18.080 ns**（负裕量），功能验证通过后必须收敛时序
   （可试 162°/171° 折中，或对 SIP 边界加带理由的 multicycle/false path），不要放着负裕量交付。

**失败时记录**：自检数码管 6 位读数 + 主设计 6 位读数 + 当时操作（连续两次以上）。

## 第 2 步：四张图片正常显示

**通过标准**

- [ ] 上电后 10~20 秒内出现 **红底 `TEAM FRAME 01`**：`TOP LEFT` 在上、箭头向上、`BOTTOM` 在下。
- [ ] 色条顺序正确：红、绿、蓝、黄、青、品红、白、黑。
- [ ] 按 KEY2 能切到 02/03/04（底色 绿/蓝/紫），**不混入旧图、不花屏**。
- [ ] 数码管 `err=0`、`count=4`。

**失败时记录**：整屏截图（不是局部）+ 数码管读数。

---

## 第 3 步：交互与音频同时工作

**通过标准**

- [ ] **手动切换**：KEY2 连按 10 次（间隔 ≥2 秒），每次都完成"渐暗 → 全黑 → 渐亮"（约 1.2 秒），一次按下只切一张。
- [ ] **自动轮播**：KEY4 按一次启动、再按一次停止；数码管模式位对应变化。
- [ ] **周期调节**：KEY3 三次循环约 5s → 10s → 2s → 5s，切换不影响进行中的动画。
- [ ] **复位**：KEY1 短按后重新扫描、重新加载、能再次出图。
- [ ] **图像在显示时持续有声音**：4 秒旋律循环不断、不明显卡顿；数码管音频位 = 4。
- [ ] 动画忙时连按 KEY2 多次 → 请求合并且最终只生效一次，不出现无限积压。

**失败时记录**：哪一步、按键次数、当时数码管读数、现象持续时间。

---

## 第 4 步：时序与稳定性

**通过标准**

- [ ] TD 布线后 **SWNS ≥ 0、HWNS ≥ 0**（现有约束下），并把报告存档。
- [ ] **连续运行 ≥ 10 分钟**自动轮播，无黑屏、无卡死、声音不断。
- [ ] **≥ 50 次切图**，无花屏、无错帧、无数码管错误位变化。
- [ ] **≥ 3 次掉电重启**（Flash 冷启动），每次都能正常出四图 + 有声音。
- [ ] Flash 里固化的是**最终版** bit，且记录 `verify_spi` 回读结果。

**失败时记录**：运行时长、异常出现的时间点、当时按键序列、屏幕与数码管照片。

## 判定口径（避免把"代码里有"当"板上通过"）

- 仿真通过 ≠ 板上通过；生成 bit ≠ 板上通过；旧版 ex4 的结果不能移用。
- 只有第 1~4 步全部满足，才把 `board_verified` 改为 `true`，并把 `PROGRESS.md` 里对应的剩余分项计入。
- 本轮交付文档中所有"已通过"均标注了证据来源（实板读数/照片/日志），未验证项一律写明"待验证"。
