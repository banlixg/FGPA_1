# 新架构播放器：第一次上板验收

状态：90/100，等待新工程实板结果。这里的“已通过”只指保存日志的仿真和TD检查，不能套用原ex4的成功记录。

## 1. 准备文件

下载并完整解压本次候选包到新的英文目录，例如 `D:\FPGA FILE\team_player_20261026`。目录中应同时保留 `board`、`rtl`、`extensions`、`release` 和 `tools`，不要只搬一个 `.al`。旧 `day5-6\lab_ex4_tf` 保留。

本次直接下载文件：`release/2026-10-26_candidate_01/team_player.bit`。

TD工程入口：`board/team_player.al`，顶层 `team_top`，芯片 `EG4S20BG256`。`.bit` 是已经生成的FPGA配置；先用它核对现象，不要求你先重新编译。

## 2. 准备TF卡：普通文件复制

1. 用读卡器连接原16 GB FAT32卡，在资源管理器确认当前盘符，不能假定仍是F。
2. 把已有卡内容备份到电脑。若根目录有其他BMP/WAV，把旧素材移到卡内一个备份子目录，本版只枚举根目录。
3. 将 `release/2026-10-26_candidate_01/media` 中 **4个IMG*.BMP和AUDIO.WAV** 复制到卡根目录。预期四图PNG和JSON清单不用复制。
4. 四个BMP均为640×480、24位、无压缩，每个921654字节。WAV为48 kHz、16位、有符号PCM、双声道，4秒简短旋律。
5. 看到同名文件时先取消并备份，不覆盖旧素材。安全弹出读卡器。

程序读取FAT32目录及簇链。这里不需要写固定物理扇区、修改分区或重新格式化。

支持范围：SD v2卡；CMD58决定块/字节寻址；FAT32主分区或无分区卷；根目录最多32个BMP/WAV候选。找到4张合格图后驻留。音频优先短文件名 `AUDIO.WAV`，否则取扫描到的首个WAV；该WAV不支持时报告音频失败，不自动转换格式。音频作为持续背景旋律播放，本版未做每图配独立音轨。

## 3. 连接和临时下载

1. 板卡断电时插TF卡；连接电脑USB-JTAG和已验证可用的HDMI显示连接，使用上次ex4已经出图的同一个HDMI接口。
2. 显示端选择正确HDMI输入并打开扬声器，先用较低音量。检查板上DIG/LED选择开关处于数码管位置。
3. 板卡供电。在BitWriter中选择本板 `EG4S20BG256`，模式 **PROGRAM_SRAM**，速度可用上次成功的5 MHz。
4. 文件列表只保留本次 `team_player.bit`，确认其路径含 `2026-10-26_candidate_01`，再Run。保留成功日志截图。
5. 下载后保持供电，等待图片加载。第一次会先黑屏，加载完成后应出图并有旋律。如果30秒仍无图，拍摄屏幕与数码管，不要反复切换程序来掩盖现象。

SRAM是临时配置，掉电后会丢失。本阶段重新上电出现工厂彩块或旧程序是可能的；需要重新下载这份bit。Flash掉电启动放在本版图像和声音确认以后执行，尚未计作完成。

## 5. 第二组检查：三个按键

| 板卡丝印 | 新程序用途 | 操作 |
|---|---|---|
| KEY1，A2 | 复位整个新播放器 | 短按后重新扫描和加载 |
| KEY2，B2 | 下一张 | 连续测试10次，每次间隔至少2秒 |
| KEY3，B1 | 轮播周期 | 默认约5秒，依次切到约10秒、约2秒、约5秒 |
| KEY4，C1 | 自动轮播开/关 | 按一次启动，再按一次停止 |

单次切图应经历“旧图渐暗 → 短暂全黑 → 新图渐亮”，约1.2秒。黑场是这项淡出/淡入效果的预期组成。长按KEY2一次只产生一次事件；动画忙时的多次按下合并保留一次，动画结束后处理，避免请求无限积压。

周期用120/300/600个视频帧配置，25 MHz像素时钟下约2.016/5.040/10.080秒。淡入淡出占用时间包含在相邻轮播请求间隔内。周期切换不影响当前动画。

## 6. 数码管诊断

位号指 `seg_sel[n]`，物理左右顺序请用照片核对，本教程不猜左右。代码扫描6位，可能与原例程只点一位的观察不同。

| 位号 | 内容 |
|---|---|
| 5 | 启动阶段：1挂载、2枚举、3/4装图、5结束、6启动失败 |
| 4 | 已成功驻留的图片数，正常4 |
| 3 | 当前帧号1～4；还没出图时不要单独据此判断成功 |
| 2 | 1表示当前有图且手动模式，3表示有图且自动模式 |
| 1 | 音频状态：4读PCM，3/5是循环收尾瞬态，7为缺少或不支持WAV等失败 |
| 0 | 优先错误：0无此类错误；B HDMI输入未就绪；C音频欠载；D图像行欠读；E淡入淡出故障；F图片不足等启动错误 |

位0为0不能独自证明音频已正常，仍须看音频位、听声音。出现C/D/E后保留照片和当时操作；复位可清除计数并重试，但这次异常仍需记录。
