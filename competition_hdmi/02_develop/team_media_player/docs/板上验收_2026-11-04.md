# 新架构播放器：实板验收记录（2026-11-04）

- 板卡：HX4S20C V1.0 / EG4S20BG256（板载 SIP SDRAM 2M×32）
- 工程：`competition_hdmi/02_develop/team_media_player`，基于 `integration/full-player` @ `ba5b221`
- 本版 bit：`handoff/2026-11-03_board_debug/artifacts/team_player_2026-11-04_timing_closed.bit`
  SHA256 `c760102a091d585f7042e8637737e36dc974bc8858c753fcc06bc8a5b6e5ab33`
- 烧写方式：QSPI Flash（`svfgen -scan_mode prog_spi` + `program_svf` + `verify_spi`），断电冷启动
- 说明：本板 **JTAG 临时配置（PROGRAM_SRAM）不可靠**（报 `PROGRAM OK` 但配置不生效，按键可重放旧程序证实），
  所有板测均走 Flash + 掉电重启。

## 1. 本轮修复的阻塞问题

### 1.1 SDRAM 写后读回校验失败（黑屏根因）

| 阶段 | 现象 | 定位 |
|---|---|---|
| 修复前 | 数码管 `F 4 5 1 0 5`：err=F、内部错误码 **5**、count=0 | 图片全部被拒 |
| 独立自检 v2（带 busy/refresh 门控） | 读命令**零响应**（`F F F F 5 1`） | 门控丢弃命令 |
| 独立自检 v3（去门控，连发 4 写 + 4 读） | 写入 `0xA5A50003` 读回 **0x0003**，4 个回应 | 控制器读写本身正常 |
| 独立自检 v5/v6（单拍事务） | 有 1 个回应但数据 `FFFF` | **单拍写/读在本 SIP 上不可靠** |

**修复**（`rtl/storage/team_sdram_port.v` 重写）：

1. 命令门控改为 `available = mem_initialized`（与基线 `frame_fifo_read/write` 一致，控制器内部仲裁刷新）；
2. 写/读各 **4 拍突发**（写同地址同数据 4 拍；读同地址 4 拍，收到第 4 个回应比对）；
3. 新增 `PREP` 状态：地址/数据比写脉冲提前一拍稳定；
4. 恢复 `VERIFY_ENABLE=1`（写后读回校验，不绕过）。

**结果**：数码管 `0 4 0 1 4 5`（err=0、内部错误码 0、**count=4**、bs=5）。

### 1.2 数码管全灭（非 RTL 问题）

板上 `DIG/LED` 选择开关（手册 SW6）拨在双色 LED 位；拨到数码管位即正常。
候选版 `seg_sel`（低有效）/`seg_data`（共阳低有效）与参考 `seg_scan.v` 一致，极性无误。

### 1.3 时序收敛

- 修复前：SWNS **−0.565 ns**、STNS −18.080 ns
- 32 条违反全部是 SIP 硬核内部 DQ 焊盘路径：
  `memory/sdram.dq[*]`（由 50 MHz@180° 移位时钟触发）→ `memory/sdram_syn_*.bpad`（由 50 MHz@0° 捕获）
- 真实约束是外部 SDRAM 芯片 tAC/tOH + 板级延迟，SDC 中无芯片模型
- 处理：仅对这 32 条焊盘路径加带理由的 `set_false_path`（`board/timing.sdc` 内有完整注释），其余域保留完整分析
- 结果：**SWNS +3.407 ns / HWNS +0.022 ns，0 违反**

## 3. 仍保留的边界与风险

1. **供应商 IP 复用范围**尚无赛方正式答复；本工程复用 video/sys PLL、HDMI 发送核、I2S 接收、SD 控制器、SDRAM 控制器（本板硬核），
   自主实现为 FAT32/BMP/帧区调度/显示控制/像素处理/淡入淡出/文件 PCM 播放器。
2. SDRAM DQ 焊盘的时序例外基于本板 SDRAM 芯片 tAC 与实板读写校验通过；
   **换板或换 SDRAM 芯片需重新核算**。
3. 音频为单条背景 WAV 循环，未实现"每图独立音轨"。
4. 长期稳定性样本为本轮 10 分钟单次 + 多次冷启动，未做长时间（小时级）老化。

## 4. 复现步骤

```powershell
# 在 board 目录
td_commands_prompt.exe build.tcl                 # -> team_player.bit
svfgen -chip EG4S20BG256 -bit team_player.bit -svf flash.svf `
       -scan_mode prog_spi -start_addr 0x0 -flash W25Q16JV
program_svf -svf flash.svf -spd 8
download -mode verify_spi -bit team_player.bit -start_addr 0x0
# 断电 -> 上电；板上 DIG/LED 开关拨到数码管位
```

TF 卡根目录：4 个 `IMG0001..4.BMP`（640×480/24 bit）+ `AUDIO.WAV`（48 kHz/16 bit/stereo）。
