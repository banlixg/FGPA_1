# 与参考ex4/ex5的实质差异及来源

本页是源码与数据路径差异说明，不冒充赛方的合规认定。

| 项目 | 本项目实现 |
|---|---|
| 本地资源发现 | 挂载FAT32、遍历根目录、沿簇链读取文件；不采用参考在物理扇区搜BM头的资源发现状态机 |
| 图片解析 | 自主BMP流解析器，校验24位BI_RGB、尺寸、偏移、正负高度、填充和边界；BGR转RGB并生成左上原点坐标 |
| 图像存储 | 启动装入4个固定帧区；每像素写后读回验证，成功才发布驻留位；发布后不再覆盖 |
| 显示读取 | 自主两行交替预取、双时钟块RAM及行标签检查，持续读已驻留帧；不同于参考加载/显示双缓冲应用架构 |
| 交互 | 自主同步去抖、单次事件、忙时合并、3档轮播周期和有效帧选择 |
| 切换效果 | 自主逐帧亮度增益流水线；淡出后等真实目标首行准备完成，再淡入；token防迟到回应 |
| 音频方法 | 从TF文件读取WAV，RIFF子块解析，16位单/双声道PCM缓冲，分数节拍输出HDMI PCM并生成N/CTS；没有接参考内部I²S测试音模块 |
| 构建 | 新顶层 `team_top` / `team_player_core`，独立 `.al`、原语时钟配置和约束；原ex4工程保留作对照 |

共同采用HDMI是题目接口要求。HDMI发射IP、串行物理包装、EG4S20 SIP SDRAM控制器及物理原语来自提供的底层平台资料；原版权声明保留，逐文件原始SHA和修改后SHA见 `board/vendor_manifest.json`。其中SDRAM包装仅改模块名和包含路径，刷新频率参数按本项目50 MHz设置；两份团队PLL配置由平台原语模板派生，使用内部反馈、自己的频率/相位组合，原模板仍留在vendor中。

没有复用参考的 `sd_card_bmp`、`bmp_read`、`frame_read_write`、`frame_fifo_read`、`frame_fifo_write`、内部I²S测试音或原应用顶层作为本项目应用逻辑。参考目录、原例程的成功板测，以及本项目的数字模型验证分别记录。

本版选用一条持续背景WAV，未实现每图单独配音轨。题目基础音频允许测试音或提示音等可识别内容，该选择可以用来演示基础音频；最终稳定性需要新bit的实板结果。若赛方对底层IP复用另有补充规定，应在最终提交前按正式答复核对，不能用此文替代答复。
