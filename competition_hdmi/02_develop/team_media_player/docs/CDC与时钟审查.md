# 时钟、跨域与验收边界

更新：2026-10-26。本页对应 `integration/full-player`，不是45分冻结包。

## 时钟配置

板载50 MHz输入。两颗PLL均采用官方原语支持的 `NOCOMP` 和内部 `VCO_PHASE_0` 反馈，VCO均为1000 MHz。参数枚举依据本机TD 6.2 `arch/eagle_macro.v`；模式依据本地《PLL用户指南》源同步/无补偿/普通模式章节。没有修改安装目录。

| 输出 | 频率 | 用途 |
|---|---|---|
| 存储PLL C0 | 50 MHz | SD协议、FAT/BMP/WAV、帧写入、存储仲裁、数码管 |
| 存储PLL C2 | 50 MHz，144° | SIP SDRAM物理时钟，使用独立BUFG |
| 视频PLL C0 | 25 MHz | 像素、按键、淡入淡出、PCM输出节拍 |
| 视频PLL C1 | 125 MHz | HDMI串行发送 |

SDRAM写方向可用名义相位窗口8 ns，读回方向12 ns，两个方向都保留STA。最终裕量以发布包保存的布线后报告为准。图片4帧共1,228,800个32位字，4,915,200字节，位于2M×32位SIP SDRAM范围内。

内部反馈模式不承诺两颗PLL之间的固定相位，因此SDC把存储和视频PLL分成异步组。**同一PLL内部不切断时序**：SDRAM C0/C2、HDMI像素/串行关系继续检查。原参考工程的像素/串行 `exclusive` 设置没有照搬。

## 所有跨域通路

| 通路 | 处理方式 | 使用前提 |
|---|---|---|
| 按键到视频域 | 每键两级同步、连续稳定计数、一次按下事件 | 10 ms去抖；长按不连续触发 |
| boot完成到视频域 | `boot1/boot2` 两级同步 | 完成后保持到共同复位 |
| 驻留有效位到视频域 | 每位两级同步；完成之后才使用 | 位仅从0变1，四帧之后不覆写 |
| 行请求视频→存储 | 请求翻转位两级同步；行号/帧号/行RAM编号保持不变 | 直到整行完成回应才可再次请求 |
| 行完成存储→视频 | 完成翻转位两级同步；错误标志保持 | 最后一个像素写入行RAM后才发回应 |
| 行像素存储→视频 | 双时钟块RAM，两行交替 | 当前读取行与预取写入行不同；标签相符才显示，否则整行黑屏并计数 |
| PCM存储→视频 | Gray指针异步FIFO，指针各两级同步，RAM同步读 | 共同复位；满时背压；空时输出静音并累加欠载 |
| 视频状态到数码管域 | 两级采样 | 仅诊断显示；不作为切图或内存控制输入 |

跨域复位统一由外部复位和两PLL锁定状态异步断言，再分别三级同步释放。单独复位一个FIFO/邮箱时钟域不受支持。没有给任意功能组合路径批量添加false path。

两级同步是亚稳态风险控制，数字仿真不能证明MTBF。Gray总线和邮箱数据仍需保持合理物理布线；异步分组本身不证明总线偏斜或模拟电气特性。已有FIFO顺序、跨时钟行预取、真实像素对比和共同复位逻辑测试，最终仍须以本板持续运行验证。

## 存储回应与切图回应

`team_sdram_port` 每次写后等待控制器排空间隔，再读回同一地址；只有32位数据一致才返回写成功。读回超时进入需共同复位的故障态，避免迟到数据混入下一事务。

四图加载完成后，帧区不再写入。显示每行预取下一行；切图只在垂直消隐开始点采纳。淡出到黑后，等待目标帧首行读入行RAM，才向淡入淡出控制器返回带token的成功回应。它不是“收到选择请求就成功”的空回应。

## 尚需板上验证

1. 本板实际SDRAM控制器的命令/刷新/忙行为及单次读取带宽；卡模型和RAM模型不替代物理IP。
2. SD MISO、HDMI/DDC等外部I/O的器件和板级延迟。目前报告的正裕量指现有约束下的已分析路径；未给未知SD卡编造输入输出延迟。
3. 数字仿真未模拟PLL锁相、亚稳态、信号完整性和显示器接收特性。
4. 2048帧PCM FIFO约42.7 ms；异常长TF读延迟可能欠载。欠载时保留采样节拍、输出静音并显示C，不宣称对任意卡的最坏延迟有保证。需要实卡连续播放记录。
5. `PHY-7002` 涉及供应商SIP SDRAM虚拟实例的位置调整警告保留在日志中；没有以删日志或换器件掩盖，需结合实际读回和板测核实。
